# Enterprise School Administration & E-Learning System
by: Wirawan Istiono

An internal web-based administration and e-learning platform engineered to streamline academic operations, student admissions, and administrative workflows. 

> **Note for Recruiters:** This project was originally developed under an NDA for an enterprise client. Sensitive configuration files, internal database credentials, and proprietary assets have been sanitized or omitted for portfolio demonstration purposes.
---

## 🚀 Key Features & Modules

* **Student & Academic Management:** Centralized dashboard for tracking student records, admissions, and academic progress.
* **Role-Based Access Control (RBAC):** Distinct permission levels and access modules for Administrators, Teachers, and Students.
* **Data Security & Optimization:** Optimized database queries and backend logic using PHP and MySQL to ensure smooth transaction handling and data integrity.
* **Asynchronous Interactive UI:** Utilized AJAX and jQuery for real-time updates and seamless user interface interaction without requiring full page reloads.
---

## 🛠️ Tools & Technologies Used

* **Backend:** PHP 7.x, CodeIgniter 3 Framework
* **Frontend:** HTML5, CSS3, JavaScript, jQuery, AJAX, Bootstrap
* **Database:** MySQL
* **Architecture:** Model-View-Controller (MVC)

---

## 📐 System Architecture & Highlights

* Engineered with **MVC Architecture** to separate business logic, presentation, and data management for long-term maintainability.
* Implemented form validation and input sanitization to prevent common web security vulnerabilities.
* Streamlined routine administrative workflows to reduce processing times and improve operational efficiency.
